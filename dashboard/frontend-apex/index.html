SOC Detection Lab

Security · AWS · 2026

Live dashboard ↗ GitHub ↗

Edge-to-cloud SSH honeypot. A Cowrie sensor on a Raspberry Pi 5 captured real attacks over a 14-day run in May 2026 without opening any inbound ports on my home network, and its logs flowed through a serverless AWS pipeline into a live React dashboard.

  • 36,440 attack sessions and 231,930 events from 1,322 IPs in 83 countries, with true source IPs recovered through the tunnel and enriched with GeoIP and ASN data.
  • Traced brute-force attacks, SSH key persistence and crypto-mining recon across 16,180 attacker commands.
  • Logged 16 malware payloads uploaded over SCP/SFTP as SHA-256 hashes (IOCs) without keeping the files, and length-redacted attempted passwords outside the attack dictionary so they never reach the dashboard or API.
  • Deployed 8 Sigma detection rules in Kibana against an offline replay of the archived run, mapped to MITRE ATT&CK tactics including credential access, persistence, discovery and command and control.
  • Pipeline built in Terraform: S3 → Python Lambdas → DynamoDB → API Gateway → CloudFront, with least-privilege IAM. Every merge is gated on 262 tests and secret scanning, deployed by GitHub Actions over OIDC.

SOC Detection Lab · architecture

As deployed for the May 6–21, 2026 run: a Raspberry Pi 5 running Cowrie, reached through HAProxy on a DigitalOcean droplet over an autossh reverse tunnel (both edge hosts since decommissioned). fluent-bit ships logs to S3, then Lambda ingest (timestamp-window correlation and MaxMind GeoLite2) → DynamoDB → aggregator → API Gateway HTTP API → React dashboard on CloudFront behind Cloudflare.

Tokyo Zero case study site · architecture

Cloudflare DNS → CloudFront (OAC, security headers, URL-rewrite function) → S3 in us-west-2, replicated to a DR bucket in us-east-1; the origin group fails over to DR on 5xx or timeout with no DNS change. The contact form posts to API Gateway → Node 20 Lambda → DynamoDB audit and SES. An hourly Synthetics canary watches three pages, and a nightly EventBridge job runs the digest Lambda (Athena over CloudFront logs) that publishes /status and /insights.
